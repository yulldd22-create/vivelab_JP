# 日本語スキンケアサイト・レイアウトサンプル

celimax.jp のトップページ構成を参考にした、オリジナルの静的HTMLテンプレートです。
商品画像・商品・価格は仮の内容です。ヘッダーは指定されたViveLabロゴ、中段の動画は提供されたファイルを使用しています。参考サイト（celimax.jp）の画像やソースコードは使用していません。

## 開き方

`index.html` をブラウザーで開いてください。インストール・ビルド・APIキーは不要です。
外部フォントや画像CDNに依存しないため、オフラインでも表示できます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップページの構造、日本語の本文・メニュー・フッター |
| `styles.css` | レイアウト・色・書体・レスポンシブ設定 |
| `script.js` | 商品データ、バナー、商品タブ、検索 |
| `menu.css` | 左寄せのヘッダー・縦型ドロップダウン・横に開くサブメニュー |
| `menu.js` | メニューのホバー・クリック・キーボード操作 |
| `footer.css` | インスタグラムとエックスだけを配置したフッター |
| `video.css` / `video.js` | 動画の表示・再生制御 |
| `assets/` | ViveLabロゴ、オリジナルSVG画像12点、提供されたMP4動画、動画のポスター画像 |
| `.nojekyll` | GitHub Pagesでそのまま公開するための設定 |

## レイアウト

1. お知らせバー・固定ヘッダー
2. パソコンは横長、スマートフォンは縦長のメインバナー
3. 商品カテゴリー
4. カテゴリー別の商品カルーセル（パソコン4列・スマートフォン2列）
5. 提供されたヘアケア動画（横縦比2:1）
6. ブランドが大切にする3つのこと
7. インスタグラムとエックスだけを配置したシンプルなフッター

## メニュー仕様

参考サイトに合わせ、ベストセラー・商品・さらに表示・ブランド・店舗情報を左寄せで配置しています。
パソコンではホバーまたはクリックで縦型メニューが開き、商品ライン別・商品カテゴリー別は横に展開します。
メニュー表示中は本文を白い半透明の背景で覆います。外側クリック・Esc・スクロールで閉じます。
下矢印でメニュー内に入り、上下矢印で項目を移動し、右矢印でサブメニュー、左矢印またはEscで戻れます。
スマートフォンでは同じ階層を折りたたみメニューとして表示します。
新商品・セール・セットは仮の商品データで絞り込みます。商品未登録のカテゴリーは準備中のメッセージを表示します。
ブランド名・商品ライン名はサンプルの内容を維持し、メニュー文言は日本語で統一しています。

## 差し替え方

- ロゴ：`assets/vivelab-logo.png`。500×200の透明PNGを元の比率のまま表示します。表示サイズは `menu.css` の `.site-header>.wordmark img` で変更できます。
- 本文・フッター：`index.html` の日本語を編集します。
- メインバナー：`script.js` の `slides` を編集します。3枚に固定されたカウンター・ドットは `index.html` にあります。
- 商品名・価格・容量・説明：`script.js` の `products` を編集します。
- 商品画像：`assets/` 内のファイルを交換し、HTMLと商品データのパスを更新します。
- メインビジュアル：HTMLの `.hero-art`、CSSの `.hero-product` を実際の画像に置き換えます。`hero-*.svg` は背景を透過したバナー用の画像です。
- 色：`styles.css` 冒頭の `:root`、`.hero-green` などを変更します。
- フォント：外部フォント未使用。端末の日本語サンセリフ書体で表示します。

## 動画

中段の特集画像を `assets/video_hair_0308.mp4` に置き換えています。
提供された動画の映像・音声を再エンコードせず、配信用にMP4のメタデータ位置を調整しています。
映像は2400×1200、長さは約15秒。画面幅に合わせ、2:1の比率を維持して表示します。
表示中は無音で自動再生・繰り返し再生し、標準のコントロールで停止・音量変更・全画面表示を操作できます。
画面外や非表示タブでは停止します。ブラウザーが自動再生を許可しない場合は再生ボタンから開始できます。
端末の「視差効果を減らす」などの設定が有効な場合は自動再生せず、手動再生できます。
3枚のカテゴリー画像・左右交互の画像紹介2セクション・間のメッセージ帯は削除しています。

## 動作範囲

メニュー、3枚のバナー切り替え、商品カテゴリーのタブ、左右スクロール、商品一覧・商品詳細、検索がブラウザー内で動作します。
動きを減らす設定ではバナーの自動切り替えとアニメーションを停止します。ダイアログはEscキーで閉じられます。
個人情報の保存や外部への送信は行いません。

フッターはインスタグラムとエックスのアイコンのみです。
インスタグラムは日本公式アカウント（https://www.instagram.com/vivelab_jp）へ新しいタブで移動します。
エックスは日本公式アカウント（https://x.com/vivelab_japan）へ新しいタブで移動します。
会社情報、サポート案内、ポリシー、著作権表記などのその他のフッター要素は表示していません。
ヘッダーのカート、商品の追加ボタン、カート画面・処理は削除しています。
会員や問い合わせなどの説明はサンプルダイアログです。注文・決済システムには接続していません。

## GitHub Pagesで公開する場合

ZIPを展開し、ZIP内のファイルと `assets/` をすべて同じ構成のままリポジトリにアップロードします。動画も `assets/` に含まれています。
GitHub の設定で Pages の公開元を対象ブランチのルートに指定します。相対パスなのでリポジトリ名の付いたURLでも使用できます。

## 確認範囲

HTMLの参照パス、画像SVG、JavaScript構文と主要操作のロジック、パッケージの構成を確認しています。
この環境ではブラウザーによる表示検証を行えていません。公開前に対象端末・ブラウザーで見た目と操作をご確認ください。
